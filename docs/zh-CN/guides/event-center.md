# 查看 Agent 公示牌

点击首页时间日期下方的当前事件一行，打开 **公示牌**。整行均可点击。
关闭 Studio 后，该入口保留在首页顶部。运行中和待处理计数保持原有的任务含义。

## 查看当前工作

**当前** 展示正在进行的工作、已公示的资源声明、资源阻塞和待处理事项。
按资源筛选，或选择 **待回答任务** 查找等待用户决定的任务。
打开记录可查看所有者、资源、状态、预计用时、关联任务和最后观察到的活动。
选择 **历史** 可查看已关闭、已撤回和已解除的记录，展开 **技术详情** 可查看记录 ID 和原始证据。

**待处理** 还会列出等待上报来源确认的 AX 候选。Agent 在 `board` 中看到同样的事项，
并通过各自所属的操作处理。

公示牌为只读界面。Agent 通过已有操作发布、更新和关闭公示。资源声明仅作协调提示。
待处理事项由对应的任务、资源或服务所有者维护，直到所有者确认状态变化。

点击任务链接，在原有详情中回答问题、响应权限请求或使用任务控制。
连接和更新链接打开各自的现有界面。关闭所属详情会返回公示牌，并保留视图和焦点。
按 Escape 返回记录列表，再按 Escape 关闭公示牌，焦点回到首页当前事件一行。

## 查看最近变化

选择 **动态** 查看按天分组的近期日志观察，展开分组可查看各条结果。
每行的花括号按钮可显示原始元数据。底部显示公示牌最近一次观察日志的时间，以及覆盖是否完整。
任务链接保留被观察的轮次，包括历史失败轮次。
使用 **加载保留历史** 读取较早记录。保留期限导致游标失效时，查看缺口并选择 **重置游标**。
刷新失败会保留最后可读数据，并提供重试。

## 限制

日志保留有上限的实例本地元数据。当前任务待处理状态复用已观察到的活动和执行结果。
观察不完整或暂不可用时会明确显示。缺少心跳不能确认工作已完成，也不会解除阻塞。

资源选项来自缓存的已注册项目及已有记录。仓库缺失时，请在项目所属入口刷新。
缺少可用本地目标的元数据引用保留 ID 供查看。

通知问题链接到现有连接界面。来源专属的可达性与投递诊断通过 `notify_status` 获取。
