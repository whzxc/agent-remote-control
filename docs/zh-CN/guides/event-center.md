# 查找变化并协调共享工作

从左下角导航胶囊打开 **事件中心**。选择 **事件** 查看变化，选择 **公示牌** 协调资源。
使用 **待处理** 查找当前需要操作的事项，使用资源筛选缩小两个视图的范围。
Studio 的待处理任务计数会直接打开 **待回答任务**。

## 处理事件

打开任务后，使用原有详情回答问题、响应权限请求，或重试、继续任务。
关闭详情会返回事件中心，并保留筛选条件。连接和更新链接会打开对应的现有控制界面。
展开分组可查看每条观察的结果和 ID。

导航胶囊统计当前去重后的待处理事项，包含未解除阻塞以及已观察到的连接、通知和更新问题。
Studio 保持原有任务计数。总数暂不可用时显示横线。
打开记录后，事项会持续待处理，直到其所有者确认状态变化。

使用 **加载保留历史** 读取较早的日志分页。
保留期限或查询范围变化导致游标失效时，查看缺口并选择 **重置游标**。
刷新失败会保留最后可读数据，并提供重试。

## 公示工作与资源状况

在 **公示牌** 选择 **发布公示**，填写单行工作意图、选择资源，并以秒为单位估计时长。
有可用本地任务时可以关联。打开公示可编辑或关闭工作范围。
关闭公示会结束资源声明，关联任务继续运行。

选择 **创建阻塞**，填写原因代码和资源状况摘要。
陈旧或不确定的阻塞仍保留为待处理。
恢复后打开记录，选择 **解除阻塞**，填写证据 ID，并提供已注册项目中可验证的 Git 提交，
或明确的非代码恢复原因，再选择建议下一步。
解除阻塞后，由用户或任务所属来源决定是否继续任务。

勾选 **历史** 可查看已关闭、已撤回和已解除记录。
详情保留原因、证据、所有者和最后有据活动。资源冲突仅作提示，观察不完整时会明确显示。

## 限制

日志保留有上限的实例本地元数据。当前任务待处理状态复用已观察到的活动和执行结果。
未知或暂不可用的观察会导致覆盖不完整。缺少心跳不能确认工作已完成。

项目选项来自 ARC 缓存的已注册项目。仓库缺失时，请先在项目所属入口刷新。
已有记录中的资源仍可选择。任务关联沿用原生派发来源限制。
本地编辑可保留来源已有关联；新增关联仍需有据的本地派发。
缺少可用本地目标的元数据引用会保留 ID 供查看。

通知问题链接到现有连接界面。来源专属的可达性与投递诊断仍通过 `notify_status` 获取。
事件中心不增加通知确认或恢复表单。
