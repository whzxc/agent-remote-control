# Why ARC

**English** | [简体中文](zh-CN/story.md)

I wanted to discuss a project without first copying its current state into a chat. Files changed, a decision moved on, Codex finished a round, and the conversation was already working from an older picture.

ARC started by letting Chat read what was true on my computer: files, project structure, and Git state. The next step was to turn a useful discussion into actual work. Once Chat could see a project, it could send a concrete task to Codex and read the result.

That made ChatGPT Chat useful as a separate thinking space. I could use its Pro reasoning option for a difficult design, then give Codex an agreed plan rather than carry the whole discussion into another window.

The remaining interruption was the return trip. I still had to notice that Codex had finished, bring its result back, and ask what to do next.

The Claude + Codex loop closes that gap. Claude reads current facts and delegates. Codex works locally. ARC notifies the bound Claude Code cloud session, and Claude can review and continue. The aim is simple: keep the discussion and the work moving together, even when I step away from the computer.
