# UI conventions

[Remote link design and phases](remote-link.md) · [Development](development.md) · [Architecture](architecture.md)

React renders. Tauri/Rust owns configuration, connections, tasks, authentication, native windows, and updates. The main window shares semantic tokens, preferences, and controls.

Activity model badges retain their intrinsic width. Codex project labels use the native project catalog, shared with project resolution through a 30-second cache. Explicit project IDs take precedence; directory matching requires an unambiguous deepest root. The filesystem directory remains separate from its display name. Task details show the project beside the Agent name, with duration, source, and model in the metadata row. Model and effort share one pill. Conversation card height follows its content, with equal padding on every side.

Timeline groups follow native turn IDs regardless of dispatch origin. External Codex history remains readable after the activity monitor no longer retains the session. History read failures stay visible and retryable instead of becoming a cached partial result. Only actual coverage limits show a partial-history notice; external origin alone does not imply missing history. Incomplete coverage is distinct from a clipped output excerpt, whose notice stays beside that output. Every turn keeps a card surface in both disclosure states, including the latest and running turn. Clicking the title row toggles the turn; its right edge shows that turn’s execution duration. The task header sums known turn execution spans and excludes gaps between turns. Native lifecycle timestamps backfill historical turn timing; missing timing is not inferred from the time the panel opened. Work blocks have no outer border or extra padding. Reasoning rows show their available summary and disappear when it is empty.

The timeline owns vertical scrolling. Tables, code blocks, file lists, diffs and command logs scroll horizontally within the stream and expand to their full content height. Wheel gestures over these blocks send horizontal deltas to the block and vertical deltas to the timeline, including diagonal gestures. Unconsumed boundary events retain native scroll chaining.

## Homepage and layout

The homepage uses the ARC mark and arc-shaped earcup connections in both themes. Five two-color palettes are ARC, cyan/blue, pink/purple, red/orange, and yellow/green. ARC retains orange and blue-purple gradients. Other palettes apply to the control-source and Agent sides.

Portrait orientation, rails and panel placement follow [Portrait layout](portrait-layout.md). The geometry below describes landscape.

ui/topology/solve.ts is the pure geometry owner. Wings share a mirrored algorithm. Initialize SVG and ResizeObserver after container refs commit. Solve only after a nonzero real viewport exists. Resizing recomputes geometry with spring transitions. Ports follow target direction with angular spacing. Earcups/outer arcs fit port ranges. Primary/secondary tentacles widen toward the root by arc length. Connecting shows root fade and moving dashes. Errors use semantic error color and background breaks. Disconnected/disabled nodes have no primary line and faded icons/names. Center-dot entry points do not participate in connections. Primary tentacles end at earcups with space before the dots.

The animator integrates stable-key center/radius, DOT scales, earcup extent, node position/scale/opacity/ports, wire opacity/availability, outer arcs, and task primitives with stiffness 210, damping 26, and roughly 8ms substeps. Each frame recomputes tentacles/arcs. One SVG draws connections. HTML nodes and fixed-size bubbles receive same-frame transforms through refs. The top connection toggle follows the animated hub's horizontal center in the same frame while retaining its top offset. Topology animation neither renders React each frame nor reads node DOM coordinates or uses layout projection. rAF stops when stationary. reduced-motion switches positions directly and stops flow. Runtime media-query changes apply immediately.

Without tasks, both wings use normal nodes, 78px rows, and a 56px compression minimum without shrinking, fading, or indenting Agents. Default node size is 44px, adjustable 32-60px. Icons, quota rings, endpoints, and outer arcs scale together. Brand icons without quota rings default to 38px. With tasks, Agent rows use 78px base/44px minimum. Active nodes scale to 1.1 relative to normal left nodes. Idle Agents remain scale 1 with normal rows and no indent when space permits. Only insufficient vertical row height or horizontal spacing shrinks them, default minimum 0.6 adjustable down to 0.4, with up to 22px centerward indent and opacity 0.62. Active nodes stay at 1.1. Outer arcs follow radius.

Wings independently compress rows. Active row height fits the sum of task heights and inter-task gaps, with 12px gaps between Agent rows. Scene height is max(viewport height, larger wing height + 140). Column spacing defaults to 2.6, adjustable 2.0-3.2. Columns center vertically. Horizontal fitting keeps the hub at the viewport center while both wings fit inside the viewport margins or dock boundary. A wing reaching its boundary displaces the hub only as far as needed. When translation alone cannot fit both wings, fitting first reduces the ring to at least 0.6 of its preferred radius. If space is still insufficient, both column distances compress by an equal ratio down to the configured minimum. Returning space restores the centered layout. The viewport margin defaults to 40px. Remaining overflow preserves the left wing and clips the right, with vertical scrolling. The center retains brand assets and earcup spacing.

Node names stay below and ellipsize. Add/manage controls occupy the ARC endpoint dots outside sorting. Do not add trailing helper buttons, coordinates, or empty-column placeholders. Pointer Events update solver drag inputs directly. Items follow both axes, but only vertical changes reorder. Other items yield through springs. Dragging does not change center balance/column spacing. Release saves order and springs back to the column. Homepage dragging uses no Motion Reorder or layout projection. Tasks reorder only within their node and pending-priority group. Aggregate slots cannot reorder. Nodes/tasks support up/down keys. Suppress click after drag. Escape/pointer cancellation restores order. Source order persists. Enabled Agent order is shared with management. Hidden items keep relative order. Task order is frontend-local. Pending tasks remain first. Top toggles keep simple tactile state changes without text, outer glow, or star decoration.

## Task detail projection
